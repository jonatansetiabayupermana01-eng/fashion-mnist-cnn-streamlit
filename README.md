# Klasifikasi Fashion-MNIST dengan CNN

Aplikasi Streamlit untuk mengklasifikasikan foto produk fashion ke 10 kelas Fashion-MNIST.

Online: https://fashion-mnist-kelompok4.streamlit.app

## Req

Python 3.10 sampai 3.13. Di Linux/macOS,

Linux / macOS:

```
git clone https://github.com/jonatansetiabayupermana01-eng/fashion-mnist-cnn-streamlit.git
cd fashion-mnist-cnn-streamlit
bash run.sh
```

Windows:

```
git clone https://github.com/jonatansetiabayupermana01-eng/fashion-mnist-cnn-streamlit.git
cd fashion-mnist-cnn-streamlit
.\run.bat
```

Buka http://localhost:8501 setelah muncul `Local URL`. Instalasi pertama mengunduh sekitar 500 MB.
